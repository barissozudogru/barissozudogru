# Developer tools

Tools for testing, CI, containers, configuration, and data privacy.

| Project | Purpose |
|---|---|
| [piiscope](https://github.com/barissozudogru/piiscope) | Detect personal data and assess privacy risk in files and databases. |
| [test-intel-mcp](https://github.com/barissozudogru/test-intel-mcp) | Find test gaps and plan tests around changes. |
| [release-intel-mcp](https://github.com/barissozudogru/release-intel-mcp) | Review release risk between Git refs. |
| [dep-health](https://github.com/barissozudogru/dep-health) | Assess npm dependency maintenance signals. |
| [envdrift](https://github.com/barissozudogru/envdrift) | Compare environment variable keys, types, and anomalies. |
| [healthcheck-gen](https://github.com/barissozudogru/healthcheck-gen) | Generate Docker HEALTHCHECK instructions. |
